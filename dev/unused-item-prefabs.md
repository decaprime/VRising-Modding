# Unused Item Prefabs
V Rising has a lot of unused item prefabs that are still in the game but are just unobtainable in a vanilla game.

This of course means they are perfect for use as special items for mod configs like currencies, special drops, or any other purpose where one may need a physical representation of an object in the game!

Below is a list of items known to be in the game but unused, Please note that this may not be an exhaustive list and mods may be using them despite not being shown here **(Please update as we figure such things out)**
